# 1.2 安装与更新

本项目是个人自用版本，使用本仓库源码构建。开发环境与常用命令见[项目说明](../../../../../README.md)。

## 构建环境

- 按 `.node-version` 安装 Node.js，按 `package.json` 的 `packageManager` 使用 pnpm。
- 使用 `rust-toolchain.toml` 指定的 Rust 工具链。
- 安装 [Tauri 2 平台依赖](https://v2.tauri.app/start/prerequisites/)；Windows 需要 Microsoft C++ Build Tools 和 WebView2。

## 本地运行与打包

在项目根目录执行：

```bash
pnpm install --frozen-lockfile
pnpm dev
```

按[项目说明](../../../../../README.md#windows-x64-构建与发布)配置更新签名私钥后，生成 Windows x64 安装包：

```bash
pnpm build
```

构建产物位于 `src-tauri/target/x86_64-pc-windows-msvc/release/`，安装包位于其 `bundle/` 子目录。

本项目仅构建 Windows x64，提供 MSI 和 NSIS 安装包。

CLI 工具可在侧边栏「应用」中安装、升级、卸载和检查版本。

## 更新自用版本

1. 备份当前应用配置目录，默认是 `~/.cc-switch/`。
2. 按[项目说明](../../../../../README.md#私有仓库认证)登录有私有仓库读取权限的 GitHub 账号。
3. 在「设置 → 关于」检查更新并点击更新，安装版会下载、校验签名、安装并重启。应用启动时也会检查更新并显示提示。

更新来自本仓库的 Release，包含自用预发布版本。便携版通过发布页下载替换；首次从没有更新功能的旧构建迁移时，需要先安装一次新构建。数据库版本不兼容时，可在恢复界面尝试升级；若本仓库没有兼容版本，应自行构建或退出应用后恢复兼容的数据库备份。

## 验证安装

启动应用，确认主窗口、托盘和所需工具面板可用，再检查已有供应商和路由配置。
