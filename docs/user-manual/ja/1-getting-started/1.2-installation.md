# 1.2 インストールと更新

このプロジェクトは個人用ビルドです。本リポジトリのソースからビルドしてください。開発環境とコマンドは[プロジェクトの説明](../../../../README.md)を参照してください。

## ビルド環境

- Node.js は `.node-version`、pnpm は `package.json` の `packageManager` に従ってください。
- Rust は `rust-toolchain.toml` で指定されたツールチェーンを使用します。
- [Tauri 2 のプラットフォーム依存関係](https://v2.tauri.app/start/prerequisites/)をインストールしてください。Windows では Microsoft C++ Build Tools と WebView2 が必要です。

## ローカル実行とビルド

プロジェクトのルートで実行します：

```bash
pnpm install --frozen-lockfile
pnpm dev
```

[プロジェクトの説明](../../../../README.md#构建与发布)に従って更新署名キーを設定してから、現在のプラットフォーム向けのインストーラーを作成します：

```bash
pnpm build
```

成果物は `src-tauri/target/release/`、インストーラーは `src-tauri/target/release/bundle/` に生成されます。

- Windows：生成した MSI を実行します。
- macOS：生成したアプリまたは DMG を使用します。署名と公証はローカルのパッケージ設定によって決まります。
- Linux：生成した deb、rpm、AppImage を使用します。Flatpak は[ビルドガイド](../../../../flatpak/README.md)を参照してください。

CLI ツールは「設定 → バージョン情報」でインストール、更新、バージョン確認ができます。

## 個人用ビルドの更新

1. アプリの設定ディレクトリをバックアップします。既定値は `~/.cc-switch/` です。
2. [プロジェクトの説明](../../../../README.md#私有仓库认证)に従い、非公開リポジトリの読み取り権限がある GitHub アカウントでログインします。
3. 「設定 → バージョン情報」で更新を確認し、更新ボタンを押します。インストール版はダウンロード、署名検証、インストール、再起動を行います。起動時にも更新を確認します。

更新元は個人用プレリリースを含む本リポジトリの Releases です。ポータブル版はリリースページから手動でダウンロードします。更新機能がない旧ビルドからの移行には、一度だけ手動インストールが必要です。データベースに互換性がない場合は復旧画面から更新を試し、対応版がなければ互換性のあるソースからビルドするか、終了後に互換性のあるバックアップを復元してください。

## インストールの確認

アプリを起動し、メインウィンドウ、トレイ、必要なツールパネル、既存のプロバイダーとルーティング設定を確認します。
