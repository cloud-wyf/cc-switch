# 1.2 安装与更新

本项目是个人自用版本，使用本仓库源码构建。开发环境与常用命令见[项目说明](../../../../README.md)。

## 构建环境

- 按 `.node-version` 安装 Node.js，按 `package.json` 的 `packageManager` 使用 pnpm。
- 使用 `rust-toolchain.toml` 指定的 Rust 工具链。
- 安装 [Tauri 2 平台依赖](https://v2.tauri.app/start/prerequisites/)；Windows 需要 Microsoft C++ Build Tools 和 WebView2。

## 本地运行与打包

在项目根目录执行：

```bash
pnpm install --frozen-lockfile
pnpm dev
```

生成本机平台的安装包：

```bash
pnpm build
```

构建产物位于 `src-tauri/target/release/`，安装包位于 `src-tauri/target/release/bundle/`。

- Windows：运行生成的 MSI 安装包。
- macOS：使用生成的应用或 DMG；签名和公证由本机打包配置决定。
- Linux：使用生成的 deb、rpm 或 AppImage；Flatpak 参见[构建说明](../../../../flatpak/README.md)。

CLI 工具可在「设置 → 关于」中安装、升级和检查版本。

## 更新自用版本

1. 备份当前应用配置目录，默认是 `~/.cc-switch/`。
2. 更新本项目源码后重新安装依赖并执行 `pnpm build`。
3. 退出正在运行的应用，再安装或替换为本次生成的版本。

应用更新由本地构建完成。数据库版本不兼容时，应使用支持该数据库版本的源码构建，或退出应用后恢复兼容的数据库备份。

## 验证安装

启动应用，确认主窗口、托盘和所需工具面板可用，再检查已有供应商和路由配置。
