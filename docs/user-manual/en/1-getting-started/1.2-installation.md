# 1.2 Installation and Updates

This is a personal build made from this repository. See the [project instructions](../../../../README.md) for the development environment and commands.

## Build Requirements

- Use the Node.js version in `.node-version` and the pnpm version in `package.json` (`packageManager`).
- Use the Rust toolchain specified in `rust-toolchain.toml`.
- Install the [Tauri 2 platform prerequisites](https://v2.tauri.app/start/prerequisites/). Windows requires Microsoft C++ Build Tools and WebView2.

## Run and Build Locally

Run these commands from the project root:

```bash
pnpm install --frozen-lockfile
pnpm dev
```

Configure the updater signing key as described in the [project instructions](../../../../README.md#windows-x64-构建与发布), then build the Windows x64 installers:

```bash
pnpm build
```

Windows x64 build outputs are in `src-tauri/target/x86_64-pc-windows-msvc/release/`; MSI and NSIS installers are in its `bundle/` directory.

Run the generated MSI or NSIS installer on Windows x64.

CLI tools can be installed, updated, uninstalled, and checked on the Apps page in the sidebar.

## Update the Personal Build

1. Back up the app configuration directory, which defaults to `~/.cc-switch/`.
2. Authenticate with a GitHub account that can read the private repository; see the [project instructions](../../../../README.md#私有仓库认证).
3. Check for updates under Settings → About and click Update. Installed builds download, verify the signature, install, and restart. The app also checks for updates at startup.

Updates come from this repository's Releases, including personal prereleases. Portable builds open the release page for a manual download. Builds without an updater need one manual installation to enable this flow. If the database version is incompatible, try updating from the recovery screen; if no compatible release exists, build from compatible source or restore a compatible database backup after quitting the app.

## Verify Installation

Launch the app and check the main window, tray, required tool panels, existing providers, and routing configuration.
