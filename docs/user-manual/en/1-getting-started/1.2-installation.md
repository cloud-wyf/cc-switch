# 1.2 Installation and Updates

This is a personal build made from this repository. See the [project instructions](../../../../README.md) for the development environment and commands.

## Build Requirements

- Use the Node.js version in `.node-version` and the pnpm version in `package.json` (`packageManager`).
- Use the Rust toolchain specified in `rust-toolchain.toml`.
- Install the [Tauri 2 platform prerequisites](https://v2.tauri.app/start/prerequisites/). Windows requires Microsoft C++ Build Tools and WebView2.

## Run and Build Locally

Run these commands from the project root:

```bash
pnpm install --frozen-lockfile
pnpm dev
```

Build an installer for the current platform:

```bash
pnpm build
```

Build outputs are in `src-tauri/target/release/`; installers are in `src-tauri/target/release/bundle/`.

- Windows: run the generated MSI.
- macOS: use the generated application or DMG. Signing and notarization depend on the local packaging configuration.
- Linux: use the generated deb, rpm, or AppImage. See the [Flatpak build guide](../../../../flatpak/README.md) for Flatpak.

CLI tools can be installed, updated, and checked under Settings → About.

## Update the Personal Build

1. Back up the app configuration directory, which defaults to `~/.cc-switch/`.
2. After updating this project's source, install dependencies again and run `pnpm build`.
3. Quit the running app, then install or replace it with the generated build.

App updates use local builds. If the database version is incompatible, build from source that supports it, or quit the app and restore a compatible database backup.

## Verify Installation

Launch the app and check the main window, tray, required tool panels, existing providers, and routing configuration.
