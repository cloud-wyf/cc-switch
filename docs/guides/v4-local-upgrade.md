# 自用版 4.0 源码升级

本次同步基于上游 `3af748231729d34d5dffdc49efda37188e35fc04`，包含 `v4.0.2` 和之后的四个提交。自用源码版本为 `4.0.3-1`。同步源码不会自动更新已安装的应用；发布流程仍按项目 README 执行。

## 新入口

- 供应商页面分为直连、路由、聚合。标签只改变查看内容，实际切换通过页面按钮完成。
- TypeScript 代理脚本仍在供应商编辑器中配置，也可以在卡片上独立启停。开启当前供应商的脚本会启动路由；已处于聚合模式时继续保持聚合。
- 详细请求日志可从应用页头进入，也可在「设置 → 本地路由」配置正文上限和保留天数。原有分类、多选过滤、过滤记忆和独立日志库继续保留。
- 退出单个应用的路由不会停止共享服务。全局关闭仍会将应用退回直连；有脚本运行时，应用页在退出前提示脚本将不再执行。
- CLI 安装和升级移到侧边栏「应用」；会话、用量、MCP、Skills 和提示词均有独立入口。

## 配置与数据库

4.0 切换供应商时只更新供应商相关字段。共享配置直接保留在客户端文件中，「通用配置片段」由上游的新配置机制取代。原有供应商脚本及其开关继续保存在供应商元数据中。

自用数据库已使用版本 21，不能套用上游的版本 20。此次沿用自用 19/20/21 的迁移历史，增加 **21 → 22**，只为 MCP 增加 Pi 启用列。独立日志库继续独立于配置备份和云同步。

实际首次运行新版时会按现有机制备份并迁移主库。仅合并源码、编译和运行隔离测试不会迁移日常使用的数据。需要回到旧应用时，应关闭应用并恢复升级前相匹配的主库备份；不要把上游原版安装包直接覆盖到自用版的数据目录上。

## 自用约束

保留原供应商名单及 NewAPI / 自定义网关入口，同时吸收保留供应商的上游协议、模型和参数更新。手动配置和旧供应商数据兼容能力继续保留。私有更新源、公钥、Windows x64 的 MSI/NSIS 构建以及本机发布流程不变。

详细同步来源、验证记录和未纳入的上游内容见 [上游同步指南](upstream-sync.md)。
